

# Pentecost

Pentecost is a Minecraft 1.20.1 mod loader. It runs Forge, Fabric, and Quilt mods together in one game. Files make it.

NOTE: it now attaches to your launcher via the installer in releases, I am still waiting for Mojang to accept my APPID request


## What it does

- Loads Forge, Fabric and Quilt mods side by side.
- Adds its own settings screen, profiles, a performance meter and sound control.
- Spreads chunk unloading and slows far-away mobs to keep ticks short.
- WWLS (World Wide Local Server) lets friends join your world with a room code. No port forwarding setup by hand.
- Offers optional Microsoft sign-in so you play online with your own account.

## Microsoft sign-in

Pentecost uses the Microsoft device code flow. You sign in on microsoft.com, so Pentecost never sees your password.

- Pentecost keeps one refresh token on your PC so you stay signed in. Signing out deletes it.
- The Minecraft token is used only to start your own game session and to join servers.
- Pentecost sends no account data to any server run by KHI.
